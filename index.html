Set up object recognition

To identify objects, Nammooru uses Google Gemini Vision — a free AI service. You need a free API key.

  1. Go to aistudio.google.com/app/apikey
  2. Sign in with your Google account
  3. Click “Create API key” and copy it
  4. Open api-config.json in the Nammooru folder
  5. Paste your key as the value of "geminiApiKey"
  6. Save the file and restart the server (run this.bat)

Photo upload and preview still work without an API key.
